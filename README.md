# Real or AI?

1. Create a free account at sightengine.com and copy your API user and API secret.
2. Push this folder to a GitHub repo, then import it at vercel.com (framework: Other).
3. In Vercel, Project Settings > Environment Variables, add:
   - SIGHTENGINE_USER
   - SIGHTENGINE_SECRET
4. Redeploy. Open your Vercel link and upload a photo.
